# 重要命令
考虑使用icloud共享目录，命令的运行旨在只做必要改动
```sh
## 古文观止
font assignment -text ./text/gwgz -handout ./handout/gwgz   #批量生成作业，运行一次后很少要跑
font typeface -font-name Kexin -handin ./handin/gwgz/<指定作业文件名> #叠加方式编辑字体文件, 作业文件名可以通过tab辅助填写
font publish html -font-name Kexin -text ./handout/gwgz/<指定课文文件名> #逐一添加的方式生成html, 课文文件名可以通过tab辅助填写
```
